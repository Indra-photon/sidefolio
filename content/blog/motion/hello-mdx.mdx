This post exists to prove the whole chain works: frontmatter is validated,
MDX compiles at build time, fenced code is highlighted by **shiki** with a
light and a dark theme, and interactive components render inline.

Inline code like `transform: scale(0.97)` or `useState()` is highlighted too.

## A fenced block

```tsx
export function Button({ children }: { children: React.ReactNode }) {
  return (
    <button className="transition-transform duration-100 ease-out active:scale-[0.97]">
      {children}
    </button>
  );
}
```
