This post lives at `content/blog/motion/springs/`, so its category path is
`["motion", "springs"]` and it renders under the **Springs** subcategory in the
sidebar, inheriting Motion's colour.

```css
.spring {
  transition-timing-function: linear(0, 0.3, 0.7, 1.05, 1);
}
```
